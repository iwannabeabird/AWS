# 1. RDS란?
RDS(Relational Database Service)는 AWS에서 제공하는 완전 관리형 관계형 데이터베이스 서비스로, 사용자가 DB를 직접 설치하거나 운영하지 않고도 손쉽게 생성, 관리, 백업, 확장할 수 있도록 도와준다.
MySQL, PostgreSQL, Oracle, SQL Server 등 다양한 DB 엔진을 지원하며, 자동 백업, 고가용성 구성, 성능 모니터링 등의 기능을 제공한다.

## 1.1 RDS의 개념과 특징
사용자는 복잡한 DB 설치, 유지보수, 백업, 복구, 보안 구성 등을 직접 하지 않고, 몇 번의 클릭 또는 명령어 만으로 DB를 생성하고 운영할 수 있다.
또한, MySQL, PostgreSQL, MariaDB, Oracle, Microsoft SQL Server 그리고 AWS가 자체 개발한 고성능 엔진인 Amazon Aurora 등 다양한 관계형 DB 엔진을 지원한다.

**RDS의 주요 특징**
- 자동화: 설치, 패치, 백업, 복구 등이 자동화 되며, Point-in-time 복구로 데이터 손실을 최소화한다.
- 성능 및 확장성: CPU, 메모리, 스토리지 조정이 쉽고, 읽기 전용 복제본(Read Replica)으로 성능을 향상시킬 수 있다.
- 보안: VPC 격리, 데이터 암호화, IAM과 보안 그룹으로 세밀한 접근 제어가 가능하다.
- 고가용성: Multi-AZ 배포로 장애 시 자동 전환되어 다운타임을 최소화한다.
- 다양한 DB 엔진 지원:  MySQL, PostgreSQL, MariaDB, Oracle, Microsoft SQL Server, Amazon Aurora 등을 선택하여 운용할 수 있다.

> Point-in-time 복구 기능
>> 실수로 데이터가 삭제되거나 손상된 경우, 원하는 시점의 상태로 되돌려 데이터 손실을 최소화하는 기능이다. 전체 백업뿐 아니라 특정 시간 단위로 복구 가능하므로,
>> 유연하고 안전하게 데이터 관리를 할 수 있다.

> IAM(Identity and Access Management) 인증
>> IAM은 누가 어떤 리소스에 접근할 수 있는지를 세밀하게 관리하여 보안을 강화하기 위한 목적으로 사용한다. 사용자, 그룹, 역할(Role)을 정의하고 권한(Policy)을 부여할 수 있고,
>> 데이터베이스, S3, EC2 등 AWS 서비스 접근을 제어 가능하다. 특정 사용자나 서비스가 필요한 리소스만 접근하도록 제한하여, 불필요한 권한 남용을 방지한다.
